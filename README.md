# NEON GRID：霓虹競技場（連線版）

瀏覽器第一人稱競技遊戲。電腦用鍵盤滑鼠，手機與平板用觸控操作。
遊戲網頁與對戰伺服器都部署在 Cloudflare Workers，伺服器使用一個 Durable Object 作為唯一的對戰房間。

## 規則

- 一次只開一場，最多 8 位真人。場上真人少於 4 人時會自動補機器人，有人加入時機器人讓位。
- 每場輪流使用兩種模式：
  - 自由競技：淘汰對手得 1 分，先到 20 分獲勝。
  - 佔領中繼站：獨自站在中央塔頂每秒得 1 分，先到 60 分獲勝；兩人以上同時在塔頂就算爭奪中，誰都不得分。
- 連線版每場隨機抽一張地圖（雨巷中繼站、地下電網、天穹要塞、熔岩工業區、海岸研究站），不會連續兩場同一張；模式照順序輪流。單人練習在設定畫面自己選地圖，或選「隨機」。
  - 雨巷中繼站：方形中繼塔、南北兩條筆直的橋、對稱的掩體。
  - 地下電網：圓形電漿反應爐（玻璃頂，佔領區在爐頂）、北側兩條 0.9 公尺寬的懸空窄廊（中間是空的）、南側一條斜向磁浮軌道接到西側平台、平台上的防爆擋板；貨箱西側密集適合近戰、東側空曠適合遠距。
  - 天穹要塞：雲海上的浮空要塞。方形塔、往四個方向的十字天橋（東西兩條接到大樓外的陽台）、離塔 8 公尺的方形天環，藍與桃紅霓虹，外牆是看得到雲海的強化玻璃。
  - 熔岩工業區：倒角熔爐塔、四條 X 形斜向橋直接連到上層平台（沒有直橋）、地面兩排齊胸高的大管線與 4 公尺立管取代分隔牆、熔岩池（純外觀，不會受傷）。
  - 海岸研究站：八角研究塔、十字橋與陽台、塔周圍八角形排列的花台與棕櫚樹，白色混凝土；牆外是懸崖、瀑布、碼頭與海。
  - 三張新地圖的中央塔頂上方都有冠架（6.6 公尺以上，站在塔頂跳起來也碰不到）與 11 公尺的尖塔。
  - 外牆、上層平台、支柱、樓梯、兩側大樓、道具與重生點位置所有地圖相同。
- 局長 5 分鐘。倒數期間不能射擊。
- 三把武器（數值在 shared.js WEAPONS，距離傷害由 dmgAt 計算）：
  - 脈衝步槍：單發 20、每秒 6 發；15 公尺外傷害遞減，60 公尺以外剩一半。
  - 電弧散射器：8 束各 11（內圈 3、外圈 5）；越遠散得越開、命中束數變少，每束傷害 4 公尺外遞減，18 公尺剩 1/4。
  - 軌道狙擊槍：單發 90、遠近不變；彈匣 3 發、換彈 3.2 秒、每秒 0.7 發。
- 地圖道具：青色晶體回復 50 護盾（20 秒重生），琥珀色箭頭給 6 秒加速（25 秒重生）。
- 場上滿 8 位真人時，新玩家自動排隊，排隊時可先玩單人練習。輪到你時有 15 秒確認加入。每場結束後排隊的人優先上場。
- 命中、護盾、重生、比分、道具都由伺服器判定。伺服器有延遲補償，會把目標倒回你開槍當下看到的位置再判定命中。
- 快捷訊息：電腦按 T 再按數字 1 到 6，手機按「訊息」。
- 手機有瞄準輔助（準星經過敵人時減速並輕微吸附）與自動射擊，可在設定中開關；畫面掉幀時會自動降低解析度。
- 排行榜記錄連線對戰的真人戰績，以暱稱識別，分成今日（台灣時間）與總排行。

## 部署步驟

需要：Cloudflare 帳號（免費方案即可）、電腦安裝 Node.js 20 以上。

```bash
cd neon-grid-online
npm install            # 安裝 Wrangler（已鎖定版本 4.148.0）
npx wrangler login     # 開瀏覽器登入 Cloudflare
npm run dev            # 本機測試：開 http://localhost:8787
npm run deploy         # 正式部署
```

部署完成會顯示網址，例如 `https://neon-grid.你的子網域.workers.dev`。第一次部署時 Wrangler 可能會請你建立 workers.dev 子網域，照提示操作即可。把網址傳給朋友就能一起玩。

想用自己的網域：Cloudflare 後台 → Workers & Pages → neon-grid → Settings → Domains & Routes 新增。

伺服器狀態可以開 `/status` 查看（場上人數、排隊人數、比賽狀態）。

## 專案結構

```
neon-grid-online/
  wrangler.toml        Worker、靜態資源與 Durable Object 設定
  package.json
  src/worker.js        Worker 入口、Durable Object 房間、排行榜（SQLite）
  public/index.html    遊戲畫面與介面
  public/game.js       3D 畫面、音效、介面、預測與校正、觸控操作
  public/core.js       權威遊戲核心：比賽流程、排隊、機器人補位、延遲補償、道具、佔領判定
                       （伺服器與單人模式共用同一份）
  public/bot.js        機器人 AI（產生與真人相同格式的操作）
  public/shared.js     共用規則：地圖、物理、武器、模式、道具
  public/models.js     載入 public/models/*.glb（角色、三把槍、場景、道具），缺檔就沿用程式模型
  public/models/       Blender 匯出的 .glb；碰撞仍由 shared.js 的 buildMap() 決定，模型只負責外觀。
                       arena.glb（雨巷中繼站）、arena_underground.glb（地下電網）、arena_skyfort.glb（天穹要塞）、
                       arena_magma.glb（熔岩工業區）、arena_coastal.glb（海岸研究站）各自對應 buildMap('city'…'coastal')，
                       由伺服器每場隨機抽（ARENAS / ARENA_ORDER，core.js pickArena）。角色、武器與場景都有手機版 *_low.glb（models.js 的 HAS_LOW）
  public/vendor/three  three.js r128（MIT 授權），隨專案部署，不依賴外部 CDN
```

## 常改的參數（public/shared.js）

- `MATCH`：局長 `time`（秒）、開戰倒數 `countdown`、結算時間 `results`、邀請確認秒數 `offerSec`、機器人補位到幾人 `fillTo`。
- `MODES`：兩種模式的名稱與分數上限。
- `WEAPONS`、`PICKUPS`、`PICKUP_TYPES`：武器數值、道具位置與效果。
- `MAX_PLAYERS`：一場人數上限（預設 8）。
- `MAX_QUEUE`：排隊上限（預設 64）。
- `SEND_EVERY`：每幾個 1/60 秒的操作打包送出一次。預設 3，即每秒 20 則訊息。

修改 `shared.js` 後請把 `VERSION` 加 1。舊頁面連線時會被提示重新整理，避免新舊規則混用。

改地圖（`buildMap(arena)`）時還要注意：

- 每個碰撞盒最後一欄是它在 Blender 裡所屬的物件名稱，`.glb` 照這些數字建。改完要重新匯出 `arena_layouts.json` 給 Blender 腳本（步驟寫在 `gen_arena.py` 開頭），否則模型和碰撞會對不上。
- 每張地圖的天空、霧、燈光色調在 `game.js` 的 `ARENA_LOOK`，招牌文字在 `ARENA_SIGNS`。
- 機器人導航點在 `LAYOUTS[arena].nodes`。新增的牆或貨箱不能蓋住重生點（`SPAWNS`）、道具（`PICKUPS`）或導航點，且所有導航點都要連得到佔領區；伺服器在換地圖時會重建碰撞與導航，並把所有人移到重生點。

## 免費額度估算

Durable Objects 免費方案每天 10 萬次請求、13,000 GB-s，UTC 00:00（台灣早上 8 點）重置。
玩家送進伺服器的 WebSocket 訊息每 20 則算 1 次請求，伺服器送出的訊息不計費；網頁本身是靜態資源，不計入。

本專案每位玩家每秒送約 20 則操作（加上每 2 秒 1 則延遲回報），約等於每秒 1 次請求：

| 場上人數 | 每天約可玩 |
| --- | --- |
| 4 人 | 約 7 小時 |
| 8 人 | 約 3.4 小時 |

機器人在伺服器內部運作，不會傳訊息，所以不消耗請求額度。只開著主選單的人每 15 秒查詢一次在線人數，排隊或玩單人模式的人只有延遲回報，用量都很小。超過額度當天會無法連線，不會自動扣款。

## 已知限制

- 房間建在第一位連線者附近的機房，跨國遊玩延遲會比較高。
- 只有基本防護（訊息頻率、大小、射速、移動速度上限），不是完整反作弊。
- 字型從 Google Fonts 載入，載入失敗時會改用系統字型。
- 排行榜以暱稱識別，任何人用同一個暱稱都會累計到同一筆紀錄。
- 軌道狙擊槍沒有瞄準鏡縮放。
